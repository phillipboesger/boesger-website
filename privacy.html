Google Account Data (Personal Automation System)

Phillip Bösger runs a self-hosted automation system ("Second Brain") for strictly personal, non-commercial use, which connects via Google OAuth to his own Google account only, specifically:

  • Google Calendar (read and create events)
  • Google Drive (read files)
  • Gmail (read messages, create drafts)

The sole purpose is personal organization and automation (e.g. calendar overview, knowledge management, drafting his own emails). This is not an application for third parties; no other users access this system.

Data retrieved via the Google APIs is stored and processed exclusively on self-operated infrastructure (own database, own workflow server). It is never shared with third parties, never sold, and never used for advertising. Use of data obtained through the Google Workspace APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

Revoking Access

Access can be revoked at any time via Google Account settings at myaccount.google.com/permissions.
