Details for Google users

What the application does, whose data it uses and why. This is the information Google's verification refers to.

What Second Brain Does

  • Takes over tasks such as programming work, documentation and tests.
  • Remembers his notes, documents and emails in one private knowledge base and finds them again in natural language.
  • Keeps him organized with a summary of the day and the week: upcoming calendar entries, open threads and things that still need a reply.
  • Drafts replies to Phillip's own emails as Gmail drafts, which are always reviewed and sent by him manually.

Who Uses It

Second Brain is a single-user, personal application. It is used exclusively by Phillip Bösger and connects only to his own Google account. It is not offered to, sold to, or accessible by third parties, and there is no sign-up: the only account it ever connects to is the developer's own.

Google Account Data It Uses

Second Brain requests access to the following Google services, each for a single, clearly defined purpose:

  • Google Calendar: to read upcoming appointments for the daily and weekly overview, and to create personal events.
  • Google Drive: to read personal documents and notes so they become searchable in the knowledge base.
  • Gmail: to read messages for the same searchable overview, and to create drafts of Phillip's own replies.

All data retrieved through the Google APIs is stored and processed exclusively on self-operated infrastructure. It is never shared with third parties, never sold, and never used for advertising. Use of data obtained through the Google Workspace APIs complies with the Google API Services User Data Policy, including its Limited Use requirements. Details are in the Privacy Policy.
